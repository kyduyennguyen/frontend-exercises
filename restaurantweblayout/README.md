# TastyBite Restaurant Landing Page

This project is a responsive restaurant landing page built with HTML and CSS.  
It features a warm, modern dining aesthetic with a hero section, menu showcase, gallery, guest reviews, and reservation call-to-action.

This layout was inspired by the design style from:

## [Coding with Parvez](https://www.facebook.com/codingwithparvez)

## Design Reference

[Restaurant Layout Mockup PDF](./restaurant-layout-reference.pdf)

## Project Overview

- Hero section with restaurant branding and call-to-action buttons
- Feature highlight cards
- Story/about section
- Popular dishes menu grid
- Gallery section
- Guest feedback section
- Reservation CTA
- Footer navigation

## Tech Stack

- HTML
- CSS
- Google Fonts

## File Structure

- `index.html` — page structure and content
- `styles.css` — layout and styling
- `assets/` — images used throughout the page
