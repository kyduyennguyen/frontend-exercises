CSS Roadmap

Hành trình làm chủ nghệ thuật định dạng và bố cục giao diện web

01
Nền tảng

1. Nhập Môn & Box Model

  • Cách liên kết CSS (Inline, Internal, External).
  • Bộ chọn cơ bản (Selectors): Class, ID, Tag, và Độ ưu tiên (Specificity).
  • Màu sắc (RGB, HEX, HSL) và Thuộc tính Font/Text.
  • Cốt lõi: Hiểu sâu về Box Model (Margin, Border, Padding, Content Width/Height).
Mục tiêu: Biết cách căn chỉnh khoảng cách và tô màu chuẩn xác cho một phần tử.
02
Định hình

2. Định vị & Bố cục Cơ bản

  • Thuộc tính display (Block, Inline, Inline-block, None).
  • Hệ thống định vị position (Static, Relative, Absolute, Fixed, Sticky).
  • Quản lý các lớp đè lên nhau với z-index.
  • Ẩn/hiện phần tử đúng cách (opacity vs visibility vs display).
Mục tiêu: Đóng băng được thanh Header khi cuộn trang, tự tay làm các menu dropdown đơn giản.
03
Làm chủ

3. Modern Layouts

  • Flexbox: Trục chính/phụ, căn dọc/ngang (justify-content, align-items), chia tỷ lệ co giãn (flex-grow/shrink).
  • CSS Grid: Chia cột/hàng trực quan, định nghĩa vùng (grid-template-areas), căn chỉnh khoảng cách bằng gap.
Mục tiêu: Dựng bất kỳ bố cục phức tạp nào mà không cần dùng đến "float" hay "table".
04
Thích ứng

4. Responsive & Biến

  • Truy vấn thiết bị (@media queries) để thay đổi giao diện theo kích thước màn hình.
  • Đơn vị đo lường linh hoạt: % , vh, vw, và đặc biệt là bộ đôi em/rem cho font chữ.
  • Sử dụng Biến CSS (Custom Properties) để quản lý mã màu/font hệ thống đồng bộ.
Mục tiêu: Trang web hiển thị hoàn hảo trên cả điện thoại, máy tính bảng và màn hình lớn.
05
Đỉnh cao

5. Hiệu ứng & Kiến trúc

  • Tạo tương tác mượt mà với transition và các dạng chuyển đổi hình học transform (2D/3D).
  • Tự định nghĩa hoạt ảnh vô hạn bằng @keyframes và animation.
  • Tìm hiểu kiến trúc viết CSS sạch (BEM, SMACSS) hoặc cách tích hợp các CSS Preprocessors (SASS/SCSS).
🚀 Đạt thành tựu: Sẵn sàng chinh phục các CSS Framework như Tailwind, Bootstrap hoặc CSS-in-JS (Styled Components).

Các cột mốc thực hành tương ứng để "lên trình":

  1. Sau khi học xong Bước 1 & 2: Hãy thử code lại giao diện của một Thẻ sản phẩm (Product Card) hoặc một Trang Profile cá nhân tĩnh gọn gàng.
  2. Sau khi học xong Bước 3: Thử clone (sao chép) lại bố cục phần header, sidebar và danh sách bài viết của các trang báo điện tử lớn.
  3. Sau khi hoàn thành cả lộ trình: Tự làm một trang Portfolio cá nhân có hiệu ứng chuyển động bắt mắt khi rê chuột và tương thích tốt trên cả Mobile lẫn Desktop.
