Day 8 - Links Element

----------------------Links Elements----------------------

External link - Opens another website.

<a href="https://example.com">Visit Website</a>

<a href="about.html">About Us</a>

<a href="mailto:hello@example.com">Email Us</a>

Day 13 - Forms Element (Basic)

----------------------Forms Elements----------------------

Forms collect information from users.
Used for login, registration, contanct and search pages.
A form contains different input controls.
Data can be submitted to a server for processing.

<form> - Create a form

Form Attributes

action - Specifies where form data is sent.

method - Defines how data is submitted. Common values is GET and POST

autocomplete - Allows browsers to suggest previously entered values.

novalidate - Disables build-in browser validation when needed.

Best Practices

Always use labels - Associate every input with a <label>

Choose correct method:
GET
Read or Search requests
POST
Submit sensitive or larger data

Keep forms accessible - Use meaningful labels and logical structure.

Keep forms simple - Ask only for necessary information.

Day 16 - Input Attributes

----------------------Input Attributes----------------------

required - The field must be filled before submitting the form. (Mandatory field)

readonly - Users can view the value but cannot edit it. (Cannot edit)

disabled - The field is unavailable and is not submitted with the form. (Inactive field)

maxlength - Limits the maximum number of characters. (Limits text length)

placeholder - Displays a temporary hint inside the input.

value - Sets the default value of an input field.

Best Practices

Use required carefully - only require information that is truly necessary.

Use readonly for fixed values - Display information without allowing edits.

Use disabled for inactive fields - Prevent interaction with unavaliable inputs.

Keep forms simple - Use only the attributes needed for a better UX (user experience).

Day 17 - Button Element

----------------------Button Element----------------------

button tag - Defines a clickable button. Buttons perform actions when users click them.

Commonly used in forms and interactive elements webpages.

HTML provides different types for different purposes.

Button Types

submit - Submits the form data to the server. (Sends form data)

reset - Restores all form controls to their initial values. (Restores form controls)

button - Performs custom actions when handled with JS. (Custom JS actions)

Best Practices

  • Always set button type.
  • Use clear button text.
  • Accessible buttons: Use meaningful text instead of generic labels like "Click".
  • Keep actions obvious: users should immediately understand what the button does.

Day 18 - Checkboxes & Radio Buttons

----------------------Button Element----------------------

Checkboxes allow selecting multiple options: skills, hobbies, interests,..

Radio buttons allow selecting only one option: gender, payment method, delivery option,...

Both are commonly used in HTML5 forms.

Use labels for better accessibility.

Best Practices

  • Always use labels: associate every option with a <label>
  • Group radio buttons: use the same name attribute for related radio buttons.
  • Clear option names: use meaningful labels users can easily understand.
  • Accessible forms: ensure options are keyboard and screen-reader friendly.
